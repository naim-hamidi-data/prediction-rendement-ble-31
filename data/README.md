# Données

- raw/ : fichiers sources conservés sans modification.
- processed/ : tableaux nettoyés et indicateurs calculés.
- evaluation/ : rendement 2026 destiné au test final, séparé des données d’apprentissage.

Documenter chaque source dans docs/sources.md. Ne pas ajouter automatiquement des archives météo volumineuses au dépôt. Les fichiers nécessaires mais non publiés seront accompagnés d’instructions de récupération.
